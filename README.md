# IPL Analytics Project

This project focuses on **IPL data analysis**, leveraging two datasets for comprehensive insights:
- **ipl_all_matches_data_cleaned** (1K records)
- **ipl_ball_by_ball_data_cleaned** (250K records)

Due to GitHub's 25MB file size limit, only the **ipl_all_matches_data_cleaned** dataset is available in this repository. The larger dataset is used locally for advanced analysis.

## Features
- Batting, Bowling, and Team Oriented KPIs analysis with Power BI & DAX
- Data cleaning & transformation using Python and SQL
- Cricket analytics dashboard visualization

Feel free to contribute and optimize the visualizations!
